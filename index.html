How the hybrid part works

Every request is single-turn text. In Auto mode the app first asks Chrome’s on-device model (Gemini Nano). If the material is short and the model is ready, the answer never leaves your device — private, offline, free. If the material is long, or the device has no local model, the same prompt goes to Gemini in the cloud instead. The badge above each result shows which path answered.

Built with Firebase AI Logic (hybrid inference) + App Check + Authentication + Firestore + Remote Config. On-device inference needs Chrome 139+ on desktop. Source: Firebase AI Logic hybrid docs.

BelajarKu AI — built for #BuildHybridAI 2026. Open source (MIT). No study material is stored on any server except your own Firebase project, and only when you press “Save this study set”.
